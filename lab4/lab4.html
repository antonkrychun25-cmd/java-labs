Теоретичні відомості з матеріалу тесту

1. JavaScript у вебдокументі: Код JS додається на HTML-сторінку за допомогою тегу <script>.

2. Змінні: У сучасному JavaScript для оголошення змінних використовуються ключові слова let (змінна) та const (константа).

3. Повідомлення: Функція alert() відображає модальне вікно з повідомленням та кнопкою ОК.

4. Порівняння: Оператор === виконує суворе порівняння значень з урахуванням типу даних (наприклад, 5 === "5" поверне false).

5. DOM та Події: Метод addEventListener() дозволяє призначити обробник подій на елемент без зміни HTML-коду.
